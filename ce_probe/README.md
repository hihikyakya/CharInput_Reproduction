# 문자 입력과 ID 입력의 영어 다음 단어 예측 대조 실험

이 폴더는 논문의 **독립 보조 실험**을 재현한다. 원고에 실린 WikiText-103·LAMBADA 단회 실행의 원자료나 체크포인트는 이 폴더에 없다. 여기서 학습하는 세 모델은 직전 한 단어만으로 다음 단어의 공통 클래스 분포를 예측한다. 문단을 넘어서는 전이는 사용하지 않는다.

## 실행

Python 3.12.14와 NumPy 2.3.5로 실행하였다. GPU, 네트워크, 외부 데이터 다운로드가 필요하지 않다. 다음 명령은 이 폴더에서 실행한다. 첫 실행 전에 NumPy가 없다면 requirements.txt에 지정된 버전을 설치한다.

```sh
python run_probe.py --out rerun
python check_probe.py --compare rerun
```

`run_probe.py`는 ID, 문자, 가중치 공유 ID 모형을 각각 다섯 번 학습한다. `check_probe.py`는 세 모형의 모든 파라미터 그룹에 대해 방향미분을 유한차분으로 검증하고, 재실행의 모형·시드·선택 스텝·파라미터 수와 수치를 저장값에 대조한다. 연산 백엔드가 다른 환경에는 절대·상대 오차 1e-7을 허용한다. `results/seeds.csv`는 실행별 원자료, `results/summary.csv`는 시드 평균·표본 표준편차와 시드별 차이의 요약, `results/dataset.json`은 분할 사양·데이터 지문·기준선 결과이다.

## 데이터와 분할

영문 기술문서는 CPython 3.12.14 표준 라이브러리의 `pydoc_data.topics`에서 가져왔다. 검색 경로는 `Lib/pydoc_data/topics.py`이며, 배포 조건은 `data/PYTHON_LICENSE.txt`에 수록하였다. `data/probe.jsonl.gz`에 본 실험용 전처리 자료를 포함했다. 독립 실행 시 Python 배포판의 문서 버전에 의존하지 않는다. 같은 CPython 버전에서 `python make_corpus.py`로 자료를 다시 생성할 수도 있다.

- 전체 79개 항목명을 고정 문자열 `word-input-study-v1/`와 항목명의 SHA-256 순서로 정렬하고 앞에서부터 59/10/10개를 학습·검증·시험에 배정한다. 알파벳으로 시작하지 않는 문단과 특정 제목 표시를 제외하고, 소문자 ASCII 영문 연속열만 단어로 추출한다. 8단어 미만 문단과 정확히 중복되는 토큰열은 제외하며 중복 문단은 사전순으로 처음 등장한 항목에만 남긴다.
- 전처리 후 실제 예시를 제공하는 항목은 학습/검증/시험 49/10/7개, 문단은 378/204/118개, 인접 단어 전이는 13,795/7,139/4,760개이다. 모든 평가 항목은 학습 항목과 분리되어 있다. 서로 다른 문단 내 일부 표현이 유사할 수 있다.
- 압축 해제 후 JSONL 바이트열 SHA-256은 `1afac2fbe9bfb76f5eb8eff6c888f13378bb226c3859c4fa3c416532af62018f`이다. 각 행에 항목명, 분할, 정규화된 단어 리스트가 들어 있다.

## 모델과 평가

1. 출력 어휘는 학습 빈도 상위 511개 단어와 UNK 한 개이다. 빈도 동률은 단어 사전순으로 처리한다. 세 모델의 예측 대상은 동일한 512개 클래스이고, 출력은 선형 변환과 softmax이다.
2. ID 입력은 512×16의 학습 가능 임베딩이다. 어휘 밖 입력을 UNK의 가중치 행으로 바꾼다. 문자 입력은 각 단어의 처음 16자를 받아 26개 문자의 8차원 임베딩을 조회한다. 0으로 패딩하고 폭 3의 합성곱(8출력 채널), tanh, 위치별 공통 선형 스칼라 투영을 적용해 16차원 입력 벡터를 얻는다. 영어 알파벳 외 자료는 전처리에서 제외된다.
3. 본체의 유일한 다음 단어 예측층은 세 모델에 같은 크기로 구성하고, 같은 시드에서 출력층 초기값을 정확히 일치시킨다. ID 입력 8,192개 및 공통 출력층 8,704개로 총 16,896개, 문자 입력 417개 및 공통 출력층 8,704개로 총 9,121개 파라미터이다. 민감도 분석을 위한 공유 ID(tied) 모형에서는 출력층의 512×16 가중치 행렬을 입력 임베딩에도 사용하므로 입력·출력 중복을 제거한 총 파라미터는 8,704개이다. 공유 가중치는 조회 경로와 출력 경로 양쪽에서 기울기를 받으며 업데이트는 한 번만 수행된다. 공통 출력 바이어스는 클래스당 하나씩 유지한다.
4. 전이 빈도를 집계하여 전체 유효 전이의 평균 CE에 대한 정확한 full-batch gradient를 계산한다. Adam(학습률 0.015, β1=0.9, β2=0.999, ε=1e−8)을 120회 적용한다. 모든 업데이트 후 검증 CE를 계산하고, 모델별·시드별로 가장 낮은 스텝 한 개를 선택해 시험한다. 최솟값 동률은 가장 이른 스텝을 택한다. 시드는 11, 23, 37, 53, 71이다. 다섯 번 모두 같은 데이터 분할을 사용한다.
5. CE는 자연로그 기반 nats/단어이다. OOV 집단은 **직전 입력 단어**가 511개 단어 어휘 밖인 경우이다. 826개 OOV 전이 중 299개는 직전 입력 단어가 학습 텍스트 어디에도 나타나지 않았다. 세 모델 모두 어휘 밖 **다음 단어**를 동일한 UNK 정답 클래스로 평가한다. 시험 전이 4,760개 중 UNK 정답은 846개이다.
6. 유니그램 기준선은 각 타깃 클래스의 학습 전이 빈도에 1을 더해 정규화한다. 모든 평가에서 공통 512개 클래스를 사용한다.

| 시험 CE, 평균 ± 시드 표준편차 | 전이 수 | ID | 문자 CNN | 공유 ID |
|---|---:|---:|---:|---:|
| 전체 | 4,760 | 4.299 ± 0.012 | 4.719 ± 0.021 | 4.661 ± 0.004 |
| 입력 어휘 내 | 3,934 | 4.243 ± 0.013 | 4.711 ± 0.045 | 4.661 ± 0.005 |
| 입력 어휘 밖 | 826 | 4.566 ± 0.012 | 4.758 ± 0.098 | 4.659 ± 0.003 |
| 입력 미관측(OOV의 부분집합) | 299 | 4.243 ± 0.016 | 4.472 ± 0.129 | 4.301 ± 0.006 |

전체 시험 CE의 동일 시드 쌍 차이(문자−ID)는 평균 +0.420, 표본 SD 0.022이다. 스무딩한 유니그램 기준선은 4.739이다. 이 수치에서 ± 표시는 고정 분할에서 서로 다른 초기값의 영향을 나타낸다. 데이터 표본에 대한 신뢰구간으로 해석할 수 없다. 문자 모형은 비공유 ID보다 7,775개 적고 공유 ID보다 417개 많은 파라미터를 사용한다. 전체 및 입력 OOV 집단 모두에서 문자 모형의 평균 CE가 두 ID 모형보다 크다. 전체 시험 CE에서 문자와 공유 ID의 시드별 차이는 다섯 번 모두 양수이며 평균은 +0.059(시드 SD 0.022)이다. 공유 ID 다섯 실행과 문자 CNN 한 실행에서 선택된 스텝은 허용 상한인 120이었다. 결과는 이 학습 예산으로 한정한다. 문맥 길이 1, 특정 영문 기술문서, 간소화된 문자 CNN과 고정된 단어 출력 어휘라는 제한이 있다.

공유 ID의 점수는 입력 단어 i, 다음 단어 j에 대해 zᵢ·zⱼ + bⱼ이다. 바이어스를 제외한 점수 행렬은 대칭이며 양의 준정부호이다. 정규화된 조건부확률 자체에는 대칭 제약이 없다. 이 성질은 한 단어의 임베딩을 곧바로 출력에 투영하는 본 보조 실험의 구조에서 나온다. 사이에 Transformer가 있는 원 실험에서 가중치 공유를 적용한 결과로 외삽할 수 없다.
